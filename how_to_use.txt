Anushasan

Add a task
Type what you’re working on, set an optional duration, and add it. It will show up under Stored Tasks.

Start and switch tasks
Press Start task on a stored task. Only one task runs at a time. Press Pause task to put it back in Stored Tasks; the time you already spent stays with it. Then you can start a different one, or come back to the paused task later.

Finish a task
When you’re done, mark it Success or Failed. It moves to history with the time you spent on it, and you can’t start it again. Add a new task if you want to work on it again.

History
Open Show history to see finished tasks, their result and time spent. This stays saved on this device.

Clear all task data removes stored tasks and history after a confirmation.
