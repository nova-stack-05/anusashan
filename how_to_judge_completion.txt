Run the app from the project folder with `npm start`, then open http://localhost:8000.

Try this flow:

1. Add two tasks, for example “Read” and “Walk”.
2. Start Read and wait a little. Pause it. It should move back under Stored Tasks and show its time.
3. Start Walk. There should still only be one Active Task. Pause Walk, then start Read again. Read should keep the time it had before.
4. Mark Read Success. It should disappear from Stored Tasks and Active Task, and show in History with Success and its time. There should be no button to start it again.
5. Start Walk and mark it Failed. It should also disappear from the startable tasks and appear in History as Failed with time spent.
6. Reload the app. The unfinished tasks, active task and history should still be there.
7. Confirm there are no money labels or hourly focus circles, and try the same flow at a phone-sized viewport.

Run the focused task tests with `npm test` and syntax checks with `npm run check`.
